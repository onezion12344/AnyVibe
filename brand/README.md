# AnyVibe Brand Assets

This directory contains the canonical Yellow Sheep visual source sheets that are safe to version with the application:

- mascot-final/ — B-direction plush Yellow Sheep turnaround and action/expression references.
- mascot-explorations/ — earlier chibi-direction exploration.

Runtime-sized illustrations for the landing page live in web/static/assets/landing/. Animated in-product states live in web/static/assets/onezion/.

The 36-role professional Yellow Sheep pack stays in the separate onezion-the-yellow-sheep asset workspace until it is released deliberately. Do not mix temporary renders, video exports, print files, or secret-bearing environment files into this directory.
